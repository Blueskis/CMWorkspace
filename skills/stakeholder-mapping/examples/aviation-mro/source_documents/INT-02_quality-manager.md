# Interview notes: Quality Manager

Interviewee: Teo Siew Hwa, Quality Manager. Interviewer: CM team. 15 Sep 2026.

- On procedure changes: "Before any procedure change goes to CAAS I talk to Raj. If Raj says the engineers won't accept it, I don't send it."
