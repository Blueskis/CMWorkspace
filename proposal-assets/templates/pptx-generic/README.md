# pptx-generic

A plain business `.potx`, generated by
`skills/cm-proposal-generator/scripts/make_pptx_template.py`.

**This is not the firm's approved template**, and a deck built on it must never be handed
over as though it were. It exists so Stage 5 can produce a real `.pptx` — openable,
editable, submittable in form if not in branding — before the approved template is
available.

## What's in it

Nine layouts, the PowerPoint siblings of `../html-generic/layouts.html`:

| Layout | Placeholders |
|---|---|
| Title Slide | `client`, `title`, `subtitle`, `meta` |
| Section Header | `kicker`, `title`, `body` |
| Title and Content | `kicker`, `title`, `body`, `footer` |
| Two Content | `kicker`, `title`, `left_heading`, `left`, `right_heading`, `right`, `footer` |
| Case Study | `kicker`, `title`, `situation`, `action`, `outcome`, `metrics`, `footer` |
| Metric Row | `kicker`, `title`, `body`, `metrics`, `footer` |
| Table | `kicker`, `title`, `body`, `table`, `footer` |
| Timeline | `kicker`, `title`, `body`, `phases`, `footer` |
| Team Grid | `kicker`, `title`, `members`, `footer` |

The names match the HTML template's `{{tokens}}` exactly, which is the point: the same
`proposal_plan.json` renders to either target with no edits.

16:9, 13.333in × 7.5in. Cambria headings, Calibri body — both ship with Office everywhere,
so the deck renders the same on a reviewer's machine as on the author's.

## The theme slots

The palette mirrors `../html-generic/theme.css`, mapped so that `render_pptx.py` can ask
for a *role* rather than a colour and stay correct on any template:

| Slot | Hex | Role |
|---|---|---|
| `tx1` / dk1 | `#14213D` | headings, primary text |
| `tx2` / dk2 | `#4A5568` | body text |
| `bg1` / lt1 | `#FFFFFF` | canvas |
| `bg2` / lt2 | `#F6F8FB` | panel |
| `accent1` | `#1F6FEB` | the single accent |
| `accent2` | `#8A94A6` | captions, metadata |
| `accent3` | `#DDE3EC` | rules |
| `accent4` / `accent5` | `#B45309` / `#FEF3C7` | gap-marker amber |
| `accent6` | `#E8F0FE` | metric tiles |

## Changing it

Edit `make_pptx_template.py`, re-run it, then re-run `profile_template.py`. Do not edit
the `.potx` in PowerPoint: the generator is the source of truth, and the next run would
discard the change.
