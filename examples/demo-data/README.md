# Demo data — 3 MVPs

Three independent, self-contained demo sets for pitching AI-enabled CM tools built on
SAP ECC6→S/4HANA migration scenarios. Each folder has a raw `input.json` (what a user
would feed the MVP) and an illustrative `output.md` (what the MVP would hand back). None
of these MVPs are built yet — this is demo content only, written by hand to show the
shape of the input/output.

| Folder | MVP | Scenario |
|---|---|---|
| `cia-mvp/` | Change Impact Assessment | New Asset Accounting (FI-AA) go-live |
| `comms-mvp/` | Comms generation | MM Purchase Requisition moving to Fiori app |
| `training-mvp/` | Training material generator | SD Order-to-Cash pricing procedure change |
